## PS-01 requirements (verbatim capability list from /problems full statement)
Transaction Analysis; Mule Account Detection (dynamic risk scores, ranking, explained indicators); Money Trail Analysis (intermediaries, chains); Complaint Correlation; Graph-Based Investigation (clusters, networks); Investigation Dashboard (risk alerts, prioritised leads, timelines, network visualisations, evidence-based reports). Thematic areas: Financial Cybersecurity, AI/ML, Graph Analytics, Fraud Detection, Financial Crime Investigation, Explainable AI, Data Visualisation.

## Repo rules
Private GitHub repo named after the team (lowercase, punctuation -> single hyphen), created by the team leader on their own account, all 3-4 members added as collaborators with portal-verified GitHub handles. Shortlisted teams transfer repo ownership to the organisers before the Grand Final. (Current working repo DEEPAK455614/muletrace predates team registration; team-name/leader facts pending from the user - rename/move only on explicit owner approval.)

## Video
8-10 minutes maximum, covering the problem statement, proposed architecture/key features/tech stack, and a demonstration of the working solution. Screen recording + clear voice-over acceptable; faces optional. Upload to the team's Google Drive, grant Viewer access to hackathonccsubihar[at]gmail[dot]com, submit the URL on the portal before the deadline. Inaccessible links risk disqualification.

## Grand Final
"Teams must be ready to run their live solution, defend technical decisions, answer judges' questions, and test their application against alternate datasets provided on the spot." (guidelines section 06). No judge dataset format is published - the Import data flow (local-only, column-mapped) is the answer; format is unknowable in advance. All members must attend and explain individual contributions; webcam/mic/stable internet mandatory.

## Judging (video screening)
Problem relevance, innovation, technical architecture, functionality, demonstration quality. 25 teams shortlisted. Organisers' decisions final.
